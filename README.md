# 🐧 Linux Command Helper

一个基于 Streamlit 开发的 Linux 命令速查助手。

## 功能

- Linux命令搜索
- 分类筛选
- 命令说明
- 使用示例
- 危险等级提示

## 本地运行

安装依赖：

```bash
pip install -r requirements.txt
```

启动应用：

```bash
streamlit run app.py
```

## 项目结构

```text
app.py              # 主程序
data.py             # 命令数据库
requirements.txt    # 项目依赖
```
